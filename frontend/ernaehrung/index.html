Ein Tracker, der locker bleibt: Mengen gibt es nur als normal oder übermäßig, keine Waage, keine Gramm. Was zählt, ist die grobe Richtung über den Tag — Kalorien, Eiweiß, Ballaststoffe. Angezeigt wird deshalb eine Spanne, keine erfundene Einzelzahl.

Open Food Facts ist eine offene Datenbank, die von Freiwilligen gepflegt wird: frei nutzbar, ohne Anmeldung — dafür nicht lückenlos. Was von dort kommt, ist ein Vorschlag zum Nachbessern, keine Wahrheit; fehlende Angaben bleiben leer statt still auf null gesetzt zu werden.
